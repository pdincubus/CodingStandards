# Contributing

Expectations
- Be respectful. Balance strong opinions with evidence.
- Keep changes small and linked to a user or developer need.

Workflow
1. Create an issue and propose a measurable outcome.
2. Use the RFC template for cross-team changes.
3. After the decision, write or update an ADR.
4. Open a PR with linked issue, RFC, and ADR.
5. Add examples where helpful.

Reviews
- Each standard has owners listed in CODEOWNERS.
- Two approvals required for standards and policies.

Meetings
- Practice hour, monthly showcase, quarterly review.
- Record sessions and add links to issues.
